# Instalador do HuntLog Tibia

## Android

[**Clique aqui para baixar o APK atualizado**](https://github.com/jpcostadev/huntLog/raw/refs/heads/main/Instalador/HuntLog-Android-latest.apk)

O APK inclui as mesmas abas, relatórios, exportação Excel e calculadora de TC do desktop. As taxas de conversão ficam salvas no aparelho. Após baixar, toque no arquivo para instalar ou atualizar o HuntLog no celular.

## Windows 64 bits

[**Clique aqui para baixar e instalar a versão mais recente**](https://github.com/jpcostadev/huntLog/raw/refs/heads/main/Instalador/HuntLog-Tibia-Setup-latest.exe)

Arquivo disponível nesta pasta: `HuntLog-Tibia-Setup-latest.exe`.

Após o download, abra o `.exe` e siga as instruções na tela. O Windows pode mostrar um aviso de publicador desconhecido porque o instalador ainda não tem assinatura de código.

O binário é versionado com Git LFS para manter o histórico do código-fonte leve. Para atualizar o instalador, substitua esse arquivo pela nova build e envie a alteração para a branch `main`.
