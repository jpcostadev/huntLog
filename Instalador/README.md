# Instalador do HuntLog Tibia

## Android

[**Baixar HuntLog Tibia 1.1.9 para Android (APK)**](https://github.com/jpcostadev/huntLog/raw/refs/heads/main/Instalador/HuntLog-Android-1.1.9.apk)

O APK permite copiar a sessão importada completa. O alias [`HuntLog-Android-latest.apk`](HuntLog-Android-latest.apk) também é atualizado junto com o APK versionado.

O APK inclui as mesmas abas, relatórios, exportação Excel e calculadora de TC do desktop. Informe a cotação total de 25 TC em GP, configure as faixas de venda com quantidade mínima, tamanho do pacote e valor em reais, e simule a quantidade desejada. As taxas ficam salvas no aparelho.

## Windows 64 bits

[**Baixar HuntLog Tibia 1.1.9 para Windows (64 bits)**](https://github.com/jpcostadev/huntLog/raw/refs/heads/main/Instalador/HuntLog-Tibia-Setup-1.1.9-x64.exe)

Esta versão permite copiar o texto completo da sessão importada e inclui o espaçamento corrigido dos botões de nomes salvos. O alias [`HuntLog-Tibia-Setup-latest.exe`](HuntLog-Tibia-Setup-latest.exe) também é atualizado junto com o instalador versionado.

Após o download, abra o `.exe` e siga as instruções na tela. O Windows pode mostrar um aviso de publicador desconhecido porque o instalador ainda não tem assinatura de código.

O binário é versionado com Git LFS para manter o histórico do código-fonte leve. Para atualizar o instalador, substitua esse arquivo pela nova build e envie a alteração para a branch `main`.
