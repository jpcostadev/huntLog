# HuntLog Tibia

Aplicativo para registrar suas hunts, acompanhar XP e lucro e compartilhar seus resultados. Para apoiar o projeto, use a aba **Apoie o projeto** no aplicativo.

## Baixar

### Windows 64 bits

[Baixar a versão 1.3.42 para Windows](https://github.com/jpcostadev/huntLog/raw/refs/heads/main/Instalador/HuntLog-Tibia-Setup-1.3.42-x64.exe) · [Versão mais recente](https://github.com/jpcostadev/huntLog/raw/refs/heads/main/Instalador/HuntLog-Tibia-Setup-latest.exe)

### Android

[Baixar a versão 1.3.38 para Android (APK)](https://media.githubusercontent.com/media/jpcostadev/huntLog/refs/heads/main/Instalador/HuntLog-Android-1.3.38.apk) · [Versão mais recente](https://media.githubusercontent.com/media/jpcostadev/huntLog/refs/heads/main/Instalador/HuntLog-Android-latest.apk)

Abra o instalador no dispositivo e siga as instruções. O aplicativo também verifica atualizações diretamente neste repositório.

> Os instaladores do Windows não possuem assinatura Authenticode; o Smart App Control pode exibir um bloqueio ao executar o instalador.

## Sincronização Firebase (opcional)

No Perfil, use o mesmo e-mail e senha no desktop e no celular. Na primeira configuração, crie o Cloud Firestore em modo de produção, ative E-mail/senha em Authentication e publique as regras que aparecem em **Ajuda de configuração**. Depois, toque em **Sincronizar agora**. A conexão com o projeto HuntLog já vem configurada no app.
